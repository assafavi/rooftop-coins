# 🪙 Rooftop Coins

**Rooftop Coins** is a fast-paced 2D rooftop platform game where you run and jump across city rooftops collecting coins before time runs out.

The game works on both **desktop computers and mobile devices**.

---

## 🎮 Play Rooftop Coins

The main Rooftop Coins page lets you choose which version you want to play:

### V2 — Classic

The original Rooftop Coins experience.

### V3 — New

The upgraded version with improved graphics, effects, gameplay features, and additional scoring mechanics.

The versions are kept separate so V2 can remain available while V3 continues to be developed and improved.

---

## 🏙️ How to Play

Your goal is simple:

**Run across the rooftops, collect the coins, and reach the end before the 60-second timer expires.**

You begin each game with **3 lives**.

If you fall off a building, you lose a life.

### Double Jump

You can jump **twice while airborne**.

On a computer, press:

**W**, **Up Arrow**, or **Space**

Press the jump button again while in the air to perform a second jump.

The double jump can help you cross larger gaps or save yourself when you are falling.

### ✈️ Secret Flying Mode

There is also a **secret code** hidden in the game.

Entering the correct code unlocks the ability to **FLY**.

You'll have to discover the code yourself!

# ⌨️ Controls

## Computer

| Control                  | Action             |
| ------------------------ | ------------------ |
| **A / Left Arrow**       | Move Left          |
| **D / Right Arrow**      | Move Right         |
| **W / Up Arrow / Space** | Jump / Double Jump |
| **R**                    | Restart Game       |
| **H**                    | End Game           |

---

## 📱 iPhone / Mobile

Mobile devices use the **on-screen controls**.

Use the left and right controls to move and the **JUMP** button to jump.

Tap JUMP again while airborne to **double jump**.

The mobile version also includes on-screen **R** and **E** controls for game actions.

# 🚀 Rooftop Coins V3

V3 builds on the original game while keeping the basic Rooftop Coins gameplay.

Upgrades include:

* Improved **2.5D rooftop and building graphics**
* Multi-layer **parallax city backgrounds**
* Improved animated player character
* Character appearance upgrades as you play
* Animated spinning and glowing coins
* Coin collection effects and particles
* Jump and landing effects
* **Perfect Jump** bonuses
* **Close Call** bonuses
* Coin combo scoring
* Airborne combo scoring
* Power-ups
* Sound effects
* More dramatic final 10-second countdown
* Improved visual effects and game atmosphere

V3 can continue to be developed without changing the classic V2 game.

# 🔧 Updating the Game

Because V2 and V3 are stored separately, one version can be updated without changing the other.

## Update V2

Replace:

```text
/v2/index.html
```

with the new V2 file.

Do **not** replace the root `index.html`.

---

## Update V3

Replace:

```text
/v3/index.html
```

with the newest V3 file.

This allows V3 to continue evolving while V2 remains unchanged.

---

## Update the Version Selection Screen

Only replace the root:

```text
/index.html
```

when you want to change the page where players choose between V2 and V3.

# 🧪 Development

Rooftop Coins is being actively developed.

**Simple to learn • Fun to play • Easy to improve**

V2 serves as the stable classic version.
