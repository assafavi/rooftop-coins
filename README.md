# Rooftop Coins

A 2D rooftop platform game.

## Play the Game

Rooftop Coins is hosted using GitHub Pages.

Try to collect all the coins as fast as you can before the times runs out (60 sec)
You have 3 lives, you will lose a life if you fall off the building.
You can Double jump by Hitting the  W , Up Arrow or Space bar TWICE (help catch yourself from falling)
There is also a Secret Code that allows you to FLY

## Controls
### Computer
- A / D or Arrow Keys — Move
- w / Up Arrow / Space — Jump
- r — Restart
- h — End game

### iPhone / Mobile
Use the on-screen controls.

## Updating the Game

The live game is contained in `index.html`.
Replace `index.html` with the newest version to update the game.
